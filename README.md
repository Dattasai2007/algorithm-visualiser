# AlgoVision

Learning-focused algorithm visualizer with user input, large visualizations, Play/Pause/Reset, step explanations, icons/arrows, and complexity information.

Algorithms: Bubble Sort, Merge Sort, Binary Search, BFS, DFS.

Run `index.html` directly or with VS Code Live Server.

### BFS/DFS Input
For BFS and DFS, enter graph edges such as `A-B, A-C, B-D, B-E, C-F, C-G`. The first node is used as the starting node. You can also enter a simple node list such as `A, B, C, D`; the visualizer connects those nodes in a chain.
